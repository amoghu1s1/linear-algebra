# linear-algebra

Small Python implementations of elementary linear algebra concepts, written for practice.

## Contents

- `dot_product.py` — dot product, Euclidean norm, and the angle between two vectors.
- `gaussian.py` — solving systems of linear equations with NumPy and a hand-rolled Gauss-Jordan elimination with partial pivoting.

## Requirements

- Python 3
- NumPy (for `gaussian.py`)

## Usage

```console
python dot_product.py
python gaussian.py
```
